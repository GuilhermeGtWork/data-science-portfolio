# Projeto Análise de Dados Exploratória - Data Science

- Neste projeto utilizei um dataset de um restaurante para explorar os dados e extrair Insights que seriam relevantes para a empresa.

---

## Dataset

 O dataset contém informações como:

- valor total da conta (`total_bill`)
- gorjeta (`tip`)
- dia da semana (`day`)
- tamanho do grupo (`size`)

---

## Objetivos e Metas

- Entender os dados retirados, organizar em tabelas e gráficos, com Insights limpos e informativos.

---

## Principais Insights

- O dia com mais clientes foi sábado
- Foi registrado uma gorjeta média de aproximadamente $3
- Mesas maiores tendem a retornar mais gorjetas

---

## Bibliotecas utilizadas

- **pandas** — Manipulação e análise de dados  
- **matplotlib** — Criação de gráficos e visualizações  
- **jupyter** — Execução de notebooks  
- **ipykernel** — Integração do kernel com o VS Code
